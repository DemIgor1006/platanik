# PLATANIK — сайт-магазин з оптовим кабінетом

## Що в архіві
- `index.html`, `data/` — сам сайт (каталог, фото, банери). Працює на будь-якому хостингу.
- `api/api.php` — серверна частина: реєстрація і вхід, оптові клієнти, замовлення, заявки, відгуки. Потрібен PHP 7.4+ з SQLite (є на 99 % хостингів, окрема база MySQL не потрібна).
- `admin.html` — адмінка: підтвердження оптових клієнтів, знижки, замовлення, заявки, відгуки, завантаження оптового прайсу.

## Встановлення (10 хвилин)
1. Залийте весь вміст архіву в папку сайту (наприклад `public_html/new/` для перевірки).
2. Скопіюйте `api/config.sample.php` у `api/config.php` і вкажіть:
   - `admin_password` — пароль адмінки (без нього адмінка вимкнена);
   - `telegram_token` і `telegram_chat` — щоб замовлення й заявки приходили менеджерам у Telegram;
   - `notify_email` — копія замовлення на пошту;
   - `keycrm_token`, `keycrm_source_id` — щоб замовлення створювались у KeyCRM.
3. Папка `api/storage` має бути доступна PHP для запису (права 750 або 755).
4. Відкрийте сайт. Якщо сервер працює, на сторінці входу зникне блок «Демо-доступ», а реєстрація почне створювати справжні акаунти.
5. Адмінка: `…/admin.html`.

## Як працює опт
1. Клієнт реєструється як ФОП або юрособа → статус «Опт — чекає підтвердження», ціни роздрібні.
2. Менеджеру приходить сповіщення. В адмінці ставите статус «Опт — підтверджено» і знижку у %.
3. Після цього клієнт бачить оптову ціну поруч із РРЦ, може оформлювати дропшипінг і зберігати шаблони доставки.
4. Оптовий прайс з 1С (CSV `артикул;ціна`) завантажується в адмінці. Є ціна в прайсі — береться вона; немає — роздрібна мінус знижка клієнта.

Оптові ціни ніколи не лежать у відкритих файлах сайту: сервер віддає їх тільки після входу підтвердженого клієнта, а суму замовлення рахує сам.

## Безпека
- База та оптовий прайс зберігаються в `api/storage/<випадкова назва>/`. Для nginx додатково закрийте папку: `location ^~ /api/storage/ { deny all; }`.
- `api/config.php` не викладайте в публічний репозиторій GitHub (він у `.gitignore`).
- Сайт має працювати по HTTPS.

## Оновлення цін і залишків
`data/catalog.json` — знімок platanik.com від 15.11.2026. Наступний крок — вивантаження з 1С/ocStore в цей файл за розкладом (той самий формат: `id, n, r, cc, p, s[Київ, Харків], c, b…`).

## Що ще не перевірено на бойовому сервері
- Відправка в KeyCRM написана за їхньою документацією, але без вашого ключа не тестувалась — перше замовлення перевірте в CRM.
- Онлайн-оплата карткою: зараз це спосіб оплати в замовленні, без підключеного еквайрингу.
