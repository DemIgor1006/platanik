# PLATANIK — сайт ТОВ «ПЛА-ТАН І К»

Інтернет-магазин запчастин, аксесуарів, світлотехніки та пневматики для вантажівок і причепів.
Дизайн — макет Figma «Сайт», дані — знімок platanik.com від 29.10.2026: 344 категорії, 2 756 товарів,
ціни, залишки Київ/Харків, назви UA/RU, фото.

## Структура

| Файл / папка | Що це |
|---|---|
| `index.html` | Увесь сайт: стилі, сторінки, логіка, логотип |
| `data/catalog.json` | Категорії, товари, бренди (без фото) |
| `data/img/iNN.json`, `data/img2/jNN.json` | Фото товарів (WebP), по 100 у файлі, вантажаться при прокрутці |
| `data/brands.json`, `data/banners.json`, `data/info.json` | Логотипи брендів, банери слайдера, тексти інфосторінок |
| `tools/src/*` | Вихідний код сайту (стилі й скрипти окремими файлами) |
| `tools/build_site_data.py`, `tools/assemble.py` | Збирання `data/` зі знімка platanik.com і збирання `index.html` з `tools/src` |

## Що змінювати вручну

- **Телефони, Viber, Telegram, e-mail, адреси, графік, оптова знижка, «Лідери продажу»** — об'єкт `CONFIG` на початку `<script>` в `index.html` (і в `tools/src/app.js`, щоб зміни не загубилися при наступному збиранні).
- **Кольори** — блок `:root { ... }` на початку `<style>`.
- **Тексти блогу й дропшипінгу** — `BLOG` і `DROP` у `index.html` (`tools/src/content.js`).

`data/*.json` вручну краще не редагувати — їх перезбирає `tools/build_site_data.py`.

## Публікація (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → Branch **main**, папка **/ (root)** → Save.
Через 1–2 хвилини сайт буде на `https://<логін>.github.io/<назва-репозиторію>/`.
Власний домен підключається там же, у полі Custom domain.

## Обмеження

- Замовлення, «Купити в один клік» і заявки не надходять автоматично: сайт формує текст замовлення з номером,
  клієнт копіює його або надсилає в Telegram. Автоматична відправка (KeyCRM, 1С, Telegram-бот) — наступний крок.
- Кабінет, обране й кошик зберігаються лише в браузері відвідувача.
- Ціни й залишки — на момент знімка, без синхронізації з 1С.
